# Лабораторная работа №4: Мобильное приложение «Конвертер и аналитика валют НБМ» (Android / Java)

Нативное мобильное приложение под платформу **Android**, написанное полностью с нуля на языке **Java** (взамен **Python / Tkinter** из Лабораторной работы №3) по методологии **Spec-Driven Development** с использованием **GitHub Spec Kit (`specify` v1.4.0)** и **Google Antigravity**.

---

## Основные возможности приложения

### 1. Экран «Конвертер» (базовая функциональность + требования Лаб 3)
- **Ввод суммы**: поддержка как точки (`.`), так и запятой (`,`) в качестве разделителя дробной части, а также быстрые пресеты сумм (`50`, `100`, `250`, `500`, `1000`, `5000`).
- **Выбор валютной пары**: выпадающие списки (`Spinner`) исходной и целевой валюты (`MDL`, `EUR`, `USD`, `RON`, `UAH`, `GBP`, `CHF`, `JPY`, `PLN`, `CZK`, `TRY`, `CNY` и др.) и кнопка мгновенной смены направления `⇄`.
- **Реактивная блокировка кнопки**: кнопка **«Конвертировать»** автоматически переходит в неактивное состояние (`enabled = false`) при пустом поле суммы.
- **Точная финансовая математика (`BigDecimal`)**:
  - Учёт номинала валюты (`Nominal = 1`, `10`, `100` — например, для японской иены `JPY`).
  - Автоматическое включение базовой национальной валюты `MDL` (`1.0000`).
  - Прямая (`Foreign -> MDL`), обратная (`MDL -> Foreign`), кросс-валютная (`EUR <-> USD`) конвертация и обработка одинаковых валют (`EUR -> EUR` в пропорции `1:1`).
- **Индикация источника и актуальности**: отображение прямого и обратного единичного курса, официальной даты курса и источника (`НБМ (bnm.md)` или `Локальный кэш НБМ`).

### 2. Экран «Сравнение за неделю (7 дней)»
Отображает динамику выбранной валютной пары (`Base / Quote`) за последние **7 календарных дней**:
- **График изменения показателя во времени** (`RateTrendChartView` на базе `android.graphics.Canvas` с интерактивным касанием и выделением точек минимума и максимума).
- **Минимальное и максимальное значение за период** (с указанием точных дат).
- **Среднее арифметическое значение за период**.
- **Изменение за период в абсолютных единицах** (например, `+0.0800 MDL`) **и в процентах** (`+0.40%`).
- **Явное указание направления тенденции**: цветовой индикатор `↑ Рост`, `↓ Падение` или `→ Без изменений`.

### 3. Экран «Сравнение за месяц (30 дней)»
Отображает динамику выбранной валютной пары за последние **30 календарных дней**:
- **30-дневный график изменения курса во времени** (`RateTrendChartView`) с линией среднего значения и интерактивным просмотром каждой точки.
- **Минимум и максимум за 30 дней** (с датами).
- **Среднее значение за 30 дней**.
- **Абсолютное и процентное изменение за 30 дней**.
- **Явный индикатор направления тенденции** (`↑ Рост`, `↓ Падение`, `→ Без изменений`) и посуточная таблица значений.

### 4. Работа офлайн (режим полёта) и обработка ошибок
- **Офлайн-режим**: при отсутствии интернета (например, в режиме полёта) приложение не падает — как экран конвертера, так и экраны аналитики за 7 и 30 дней работают на основе локального постоянного кэша (`filesDir/rates_cache.json`), который переживает перезапуск приложения и явно отображает дату актуальности данных.
- **Предзагруженная история 35 дней**: локальный кэш инициализируется 35-дневным набором исторических курсов НБМ, благодаря чему месячный (30-дневный) и недельный (7-дневный) графики доступны сразу после установки приложения даже без подключения к сети.
- **Выходные и праздничные дни**: при пустом ответе `<ValCurs>` серверный клиент автоматически выполняет откат до 7 дней назад к последнему рабочему дню и выводит понятное уведомление.

## Запуск Unit-тестов (одной командой)

Все модульные тесты (`JUnit 4`) покрывают разбор XML НБМ, расчёт статистики для экранов сравнения за 7 и 30 дней (минимум, максимум, среднее, абсолютное и процентное изменение, направление тренда), поведение при пустом наборе данных, валидацию пользовательского ввода, конвертацию и работу офлайн-кэша.

В корне репозитория выполните одну команду:

**Windows (PowerShell / CMD):**
```powershell
.\gradlew.bat test
```

**macOS / Linux:**
```bash
./gradlew test
```

## Сборка и запуск Android-приложения

1. **Сборка Debug APK из командной строки:**
   ```powershell
   .\gradlew.bat assembleDebug
   ```
   Готовый установочный пакет создаётся по пути:
   `app/build/outputs/apk/debug/app-debug.apk`

2. **Установка и запуск на подключённом Android-устройстве или в эмуляторе:**
   ```powershell
   .\gradlew.bat installDebug
   ```
   Либо откройте папку проекта `lab4` в **Android Studio** и нажмите **Run (`Shift + F10`)**.
